About

Two jobs,
one mission.

By day, I'm a software engineer at Northwestern Mutual, shipping production code and learning what it actually means to build things that scale. By night (and weekends), I run a panel community for early-career women in tech — because I spent way too long feeling like I was the only one figuring this out alone.

I started hosting panels because I couldn't find the room I needed, so I built it. 500+ women later, I'm still convinced that access and community change everything. Tech doesn't have to feel like an exclusive club — and I'm here to prove it.
